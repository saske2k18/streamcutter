Privacy Policy

Last updated: 20 November 2026

StreamCutter is a personal desktop application used by a single person, its owner, to publish clips of their own livestreams to their own YouTube channel and TikTok account.

Data the app accesses

  • Google / YouTube: with the owner's consent, the app receives an OAuth token with the youtube.upload scope. It is used only to upload videos to the owner's channel. The app does not read, analyse or store any other YouTube or Google account data.
  • TikTok: with the owner's consent, the app receives an OAuth token with the user.info.basic and video.upload (and, if enabled, video.publish) scopes. It is used only to send the owner's videos to their own TikTok account and to check the upload status.

Storage

Access tokens are stored only on the owner's computer, in a local file. They are never sent to any server other than Google's and TikTok's own APIs. The app has no backend server, no analytics and no advertising, and it does not sell or share data with anyone.

Revoking access

Access can be revoked at any time: for Google at myaccount.google.com/permissions, for TikTok in the app under Settings → Security → Manage app permissions. Deleting the local token file also removes all stored access.

Google API Services

StreamCutter's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Uploads use the YouTube API Services; see the YouTube Terms of Service and the Google Privacy Policy.
